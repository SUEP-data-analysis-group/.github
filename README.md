# 上海电力大学 · Python 数据分析课程小组

**2024级 · 数据科学与大数据技术 · 三人小组**

本组织用于整理“基于 Python 的数据分析实践”课程项目，保存数据说明、分析代码、可视化图表、研究报告及汇报材料。

## 项目选题

**题目 5：家庭用电规律与负荷变化分析**

围绕家庭用电数据，分析用电量在不同时间尺度下的分布与变化，识别典型用电时段、峰谷特征及工作日与周末的差异。

## 计划分析方向

| 分析方向 | 计划内容 |
| --- | --- |
| 时间分布 | 按小时、日期统计用电量，观察日内及跨日变化 |
| 工作日与周末对比 | 比较两类日期的用电水平、负荷曲线与高峰时段 |
| 峰谷与波动特征 | 分析用电峰值、低谷及日内变化规律 |

以上为初步方向，后续将结合数据集的时间粒度、字段和质量调整，覆盖至少三个分析角度。

## 计划工作流程

1. **了解数据**：确认数据来源、字段含义、时间范围及计量单位。
2. **处理数据**：检查缺失值、重复记录、异常值与时间格式。
3. **开展分析**：完成时间统计、日期类型对比和峰谷特征分析。
4. **呈现结果**：使用 Python 生成图表，结合数据解释规律与局限。
5. **整理交付**：形成分析代码、研究报告及课堂汇报 PPT。

涉及功率与电量时，将根据数据字段和采样间隔区分统计口径。

## 课程交付

- **研究报告**：介绍数据集情况、数据处理过程、分析方法与结论。
- **Python 程序代码**：保留清晰的运行说明与分析步骤。
- **可视化图表**：支持主要分析发现，并注明指标与单位。
- **汇报 PPT**：按课程要求，在 10 分钟内完成展示。
